# Roadmap

## v0.1

- Small 3x3 dome design optimization.
- RigidTile, PointHingeConstraint, RopeParticle, and DistanceConstraint.
- Pull handle for rope-driven deployment.
- Flat-state physical deployment with gravity, damping, hinges, and rope tension.
- Comparison between optimized assembled state and physical final state.
- 4x4 saddle and wave examples.
- Simple OBJ/STL/PLY input.

## Later

- Better quad remeshing for arbitrary target meshes.
- Friction-aware string routing.
- More faithful revolute hinge constraints.
- Contact-aware rigid body simulation.
- MuJoCo or Project Chrono backend.
- 8-vertex frustum tiles.
- Fabrication checks and export.
